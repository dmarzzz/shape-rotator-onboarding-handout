§ 01 First Week — 5 steps · ~30 min · everything below opens a GitHub PR
[ 01 ]

Set up your local agent.

You're reading this inside the field-guide app, so the agent is already running. The field-kit gives it CLI tools — research, voice, content, skills.

github.com/dmarzzz/shape-rotator-field-kit

[ 02 ]

Verify your profile.

Open the editor and fill out your personal API: comm_style, contribute_interests, availability_pref, weekly_intention. Submit opens a PR.

alchemy → profile → verify + edit

[ 03 ]

Join the Matrix server.

Create an account on the homeserver and join the cohort room.

#shape-rotator-general:mtrx.shaperotator.xyz

[ 04 ]

Send your agent into Matrix.

Register your local agent as a bot in the cohort room so it can post and read on your behalf.

field-kit · /matrix-bot-setup

[ 05 ]

Do the cohort interview & quiz.

Short interview and quiz so the cohort knows what each of you brings and what you're after. Links published in Matrix once they're up.

interview + quiz · link tbd
